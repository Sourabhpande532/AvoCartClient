# UI Enhancement Task

## Objective
Improve the application's UI using Bootstrap + custom CSS while keeping all existing functionality unchanged.

---

## Strict Rules

- Do NOT modify:
  - Business logic
  - API calls or URLs
  - State management
  - Event handling
  - Backend/server code

- Work only inside the client/frontend folder
- UI/styling/layout changes only

---

## UI Requirements

### Design
- Create a modern, clean, responsive UI
- Improve spacing, typography, colors, shadows, and overall UX
- Use Bootstrap for layout/responsiveness
- Use custom global CSS for styling
- Avoid inline styles unless necessary

### Theme Toggle
Add a Light/Dark theme toggle in the Navbar.

Requirements:
- Toggle full app theme
- Smooth transitions
- Persist clean modern styling across both themes

### Effects & Animations
Add:
- Hover effects
- Smooth transitions
- Interactive UI feedback
- Modern card/button/navbar styling

### Responsiveness
Ensure proper responsiveness for:
- Mobile
- Tablet
- Desktop

---

## Consistency
Maintain consistent:
- Colors
- Typography
- Button styles
- Border radius
- Shadows
- Spacing

---

## Important
- Frontend-only changes
- No functional changes
- Keep application lightweight and smooth
- Follow modern UI inspiration from provided reference video
